# Club Code

A collection of independent C++ and [raylib](https://www.raylib.com/) teaching projects for the club.

## Learning Path

1. [Introduction](0-Introduction/) - Open a window, draw simple shapes, and handle mouse input.
2. [TicTacToe](1-TicTacToe/) - Build a classic board game.
3. [Pong](2-Pong/) - Create a two-dimensional arcade game.
4. [MiniSurvivors](3.1-MiniSurvivors/) - Start the survivor-game series.
5. [MiniSurvivors Plus](3.2-MiniSurvivorsPlus/) - Continue the series with additional features.
6. [MiniSurvivors Pro](3.3-MiniSurvivorsPro/) - Explore the more complete project stage.
7. [MiniSurvivors Ultra](3.4-MiniSurvivorsUltra/) - Follow the latest MiniSurvivors stage.
8. [Raylib Template](Raylib/) - Use the standalone raylib application template.

## Getting Started

Each folder is an independent CMake project. Start with [Introduction](0-Introduction/) and read its [setup guide](0-Introduction/README.md) for platform-specific build instructions.
